A lightweight, modular action bar replacement for World of Warcraft focused on clarity, performance, and immersive class identity.

GoblinBar reimagines the default Blizzard action bars with handcrafted artwork, dynamic class and specialization crests, and a clean fantasy-inspired interface that feels at home in Azeroth.

Features
🎨 Custom fantasy-themed action bar artwork
🛡️ Dynamic class and specialization crests
Classic: Class crests
Retail: Automatic specialization crests
⚡ Lightweight and performance-focused
🔄 Automatic spec detection (no UI reload required)
📏 Pixel-perfect layouts
🧩 Built to integrate seamlessly with the Goblin UI suite
🎮 Supports Retail, Classic Era, Hardcore, and future WoW expansions
Design Philosophy

GoblinBar is designed around three principles:

Readable — Important information should be visible at a glance.
Immersive — The UI should enhance Warcraft's art style rather than replace it.
Modular — Every component is built to work independently or alongside other Goblin UI addons.

Unlike many action bar replacements that prioritize endless customization, GoblinBar focuses on providing a polished, cohesive experience with carefully crafted visuals and minimal overhead.
